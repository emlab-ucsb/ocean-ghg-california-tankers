Overview

This document explores greenhouse gas (GHG) emissions from tankers arriving at California ports using an AIS (Automatic Identification System)-based emissions model developed in collaboration between Environmental Markets Lab (emLab) and Global Fishing Watch (GFW). The model and methodology is described extensively here.

Tankers arriving at California could be a significant source of maritime emissions, carrying crude oil, petroleum products, liquefied natural gas (LNG), and chemicals to refineries and terminals along the California coast. This report provides a preliminary exploratory data analysis (EDA) of tanker emissions based on the GFW model, covering vessel-level emissions estimates for voyages that end at California ports.

NoteData Access

The underlying data are pulled from Google BigQuery, where emLab and Global Fishing Watch store the vessel-level emissions model. Only collaborators with GFW BigQuery access can re-run the SQL queries (see R/01_pull_bq_data.R). All other users can reproduce this analysis using the pre-downloaded CSV files in the data/ folder.

The dataset includes 1,714 unique trips, across 739 unique tanker vessels, from 45 countries, that had arrival dates ranging from 2015-01-17 to 2026-07-31.

3. Exploratory Data Analysis

In this section, we conduct a preliminary exploratory data analysis (EDA) of the tanker trip emissions data. We will examine the distribution of emissions across voyages, identify key ports and routes, and explore potential trends in the data.

Earlier versions of the GFW model grouped crude oil tankers, petroleum product tankers, and chemical tankers together in a single tanker.chemical_oil class, and could not differentiate further. As of the v20260714 model version, oil tankers are identified as their own class, tanker.oil, and the SQL query underlying this report retrieves only that class. The tanker.oil category includes vessels classified as: Asphalt/bitumen tanker; Coal/oil mixture tanker; Crude oil tanker; Crude/oil products tanker; Products tanker; Shuttle tanker; Tanker (unspecified).

The entire analysis below therefore covers tanker.oil voyages only.

Next we look at a time series plot of number of tanker trips, unique tanker vessels, CO2 emissions, total hours at sea, and total distance traveled (nm), for oil tanker voyages from South Korea and India that end at California ports. We focus on the `r first_year`-`r last_complete_year` period, excluding any partial final year of data. We aggregate by the year during which each voyage arrived in California.

```{r}
#| label: fig-time-series
#| fig-cap: "Annual number of tanker trips, unique tanker vessels, CO2 emissions, total hours at sea, and total distance traveled (nm), for oil tanker voyages from South Korea and India that end at California ports."
#| fig-height: 10
annual_summary_data <- tanker_trips_of_interest_emissions_ending_in_california |>
  sf::st_drop_geometry() |>
  dplyr::filter(vessel_class == vessel_class_of_interest) |>
  dplyr::group_by(
    year = lubridate::year(arrival_date),
    from_country
  ) |>
  dplyr::summarise(
    total_trips = dplyr::n_distinct(trip_id),
    total_vessels = dplyr::n_distinct(ssvid),
    emissions_co2_mt = sum(emissions_co2_mt),
    hours = sum(hours),
    distance_nm = sum(distance_nm)
  ) |>
  dplyr::filter(year <= last_complete_year) |>
  tidyr::pivot_longer(
    cols = c(total_trips, total_vessels, emissions_co2_mt, hours, distance_nm),
    names_to = "metric",
    values_to = "value"
  ) |>
  dplyr::mutate(
    metric = dplyr::recode(
      metric,
      "emissions_co2_mt" = "CO2 emissions (MT)",
      "total_trips" = "Total trips",
      "total_vessels" = "Total vessels",
      "hours" = "Total hours at sea",
      "distance_nm" = "Total distance traveled (nm)"
    )
  )
annual_summary_data |>
  ggplot(aes(x = year, y = value)) +
  geom_line() +
  facet_wrap(metric ~ from_country, scales = "free_y", ncol = 2) +
  theme_minimal() +
  labs(x = "Year", y = "", color = "Departure country") +
  scale_color_brewer(palette = "Set1", direction = -1) +
  scale_y_continuous(labels = scales::comma, limits = c(0, NA)) +
  scale_x_continuous(breaks = seq(first_year, last_complete_year, by = 1)) +
  theme(axis.text.x = element_text(angle = 45, hjust = 1))
```
