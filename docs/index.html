Overview

This document explores greenhouse gas (GHG) emissions from tankers arriving at California ports using an AIS (Automatic Identification System)-based emissions model developed in collaboration between Environmental Markets Lab (emLab) and Global Fishing Watch (GFW). The model and methodology is described extensively here.

Tankers arriving at California could be a significant source of maritime emissions, carrying crude oil, petroleum products, liquefied natural gas (LNG), and chemicals to refineries and terminals along the California coast. This report provides a preliminary exploratory data analysis (EDA) of tanker emissions based on the GFW model, covering vessel-level emissions estimates for voyages that end at California ports.

NoteData Access

The underlying data are pulled from Google BigQuery, where emLab and Global Fishing Watch store the vessel-level emissions model. Only collaborators with GFW BigQuery access can re-run the SQL queries (see R/01_pull_bq_data.R). All other users can reproduce this analysis using the pre-downloaded CSV files in the data/ folder.

1. Data Preperation

The following code block connects to Google BigQuery and retrieves tanker voyage and emissions data for vessels arriving at California ports. This section only runs when params$pull_data is TRUE (i.e., when you have Global Fishing Watch BigQuery credentials configured). This chunk downloads the data and saves it as a CSV file in the data/ folder, which is then loaded in the next section for analysis. If you do not have BigQuery access, you can skip this section and use the pre-downloaded CSV file.

Show code 
# Code to pull data from BigQuery and save as .csv file
# Note: This can only be run by users with access to the BigQuery project and dataset
billing_project <- "emlab-gcp"

# Pull data describing all tanker trips that end in California,
# along with their associated emissions, distance traveled, hours, starting and ending ports, etc
bigrquery::bq_project_query(
  billing_project,
  here::here(
    "sql",
    "tanker_trip_emissions_ending_in_california.sql"
  ) |>
    readr::read_file()
) |>
  bigrquery::bq_table_download(n_max = Inf) |>
  readr::write_csv(here::here(
    params$data_file
  ))

2. Load Data

Here we load the tanker trip emissions data from the CSV file into R for analysis. This dataset includes vessel-level emissions estimates for voyages that end at California ports, along with associated metadata such as distance traveled, hours at sea, starting and ending ports, and more. The dataset can be directly accessed in the GitHub repo: data/tanker_trip_emissions_ending_in_california.csv.

Show code 
countries_of_interest <- c("South Korea", "India")
vessel_class_of_interest <- "tanker.chemical_oil"


tanker_trip_emissions_ending_in_california <- readr::read_csv(
  here::here(params$data_file)
) |>
  dplyr::mutate(
    class_of_interest = ifelse(
      vessel_class == "tanker.chemical_oil",
      TRUE,
      FALSE
    )
  ) |>
  dplyr::mutate(
    from_country = countrycode::countrycode(
      from_country_iso3,
      "iso3c",
      "country.name",
      nomatch = from_country_iso3
    )
  ) |>
  dplyr::mutate(
    country_of_interest = ifelse(
      from_country %in% countries_of_interest,
      TRUE,
      FALSE
    )
  )

The primary focus of the analysis is oil tankers, and on voyages departing from South Korea and India. We will explore a few figures summarizing all trips ending in California, and then filter to our vessel class and countries of interest for the remainder of the analysis.

3. Exploratory Data Analysis

In this section, we conduct a preliminary exploratory data analysis (EDA) of the tanker trip emissions data. We will examine the distribution of emissions across voyages, identify key ports and routes, and explore potential trends in the data.

First we look at the total amount of CO2 emissions, number of tanker trips, and number of unique tanker vessels, and for all tanker voyages that end at California ports in our dataset, aggregated by tanker type. The class with by far the most activity is tanker.chemical_oil, which includes crude oil tankers, petroleum product tankers, and chemical tankers. We cannot at this time differentiate further between chemica and oil tankers, but we should eventually have this capability later this year. tanker.liquified_gas are much less common in voyages ending in California.

For the remainder of the analysis after this figure, we will focus on the tanker.chemical_oil class.

Show code 
tanker_trip_emissions_ending_in_california |>
  dplyr::group_by(vessel_class, class_of_interest) |>
  dplyr::summarise(
    total_trips = dplyr::n_distinct(trip_id),
    total_vessels = dplyr::n_distinct(ssvid),
    emissions_co2_mt = sum(emissions_co2_mt)
  ) |>

  dplyr::arrange(-total_trips) |>
  tidyr::pivot_longer(
    cols = c(total_trips, total_vessels, emissions_co2_mt),
    names_to = "metric",
    values_to = "value"
  ) |>
  dplyr::mutate(
    metric = dplyr::recode(
      metric,
      "emissions_co2_mt" = "CO2 emissions (MT)",
      "total_trips" = "Total trips",
      "total_vessels" = "Total vessels"
    )
  ) |>
  ggplot(aes(
    y = reorder(vessel_class, value),
    x = value,
    fill = class_of_interest
  )) +
  geom_bar(stat = "identity") +
  facet_wrap(~metric, scales = "free_x") +
  theme_minimal() +
  labs(x = "", y = "Vessel class") +
  theme(legend.position = "none") +
  scale_fill_brewer(palette = "Set1", direction = -1)
